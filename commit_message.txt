🛡️ Sentinel: [MEDIUM] Fix XSS vulnerability in setup dialog status labels

Severity: MEDIUM
Vulnerability: The `_apply_status_label` method in `src/bitnet_launcher/gui/setup_dialog.py` used string interpolation to insert dynamic `text` into an HTML string for a `QLabel`. `QLabel` automatically parses HTML by default, leading to potential Cross-Site Scripting (XSS) or Rich Text injection if the input text contained malicious tags.
Impact: An attacker or untrusted data source could potentially inject HTML to alter the UI layout, spoof status messages, or execute unintended Rich Text parsing.
Fix: Added `import html` and applied `html.escape(text)` before interpolating the dynamic string into the `QLabel`'s HTML f-string.
Verification: Verified by passing `uv run pytest`, `uv run ruff check`, and `uv run mypy`.
