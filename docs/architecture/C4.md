## 2. Container View (C4Container)

```mermaid
C4Container
  title Container Diagram: Bitnet_Launcher Components

  Person(user, "User / Developer", "Operator of the desktop GUI or local API client.")

  Container_Boundary(c1, "BitNet Launcher Application") {
    Container(gui_layer, "PyQt6 Desktop GUI", "Python 3.11+, PyQt6", "LauncherWindow, ModelPanel, SettingsPanel, ChatPanel, HubDialog, and SetupDialog providing user interactions.")
    Container(api_layer, "Local REST API", "FastAPI, Uvicorn, Pydantic", "Local HTTP endpoints exposing model discovery, system status, and CORS-governed integration hooks.")
    Container(chat_engine, "Chat Session Engine", "Python 3.11+ (Qt-free)", "Non-blocking stdout streaming state machine managing prompt formatting, echo filtering, and token transitions.")
    Container(model_manager, "Model Discovery & Config", "Python 3.11+, Pydantic", "Models scanner, GGUF validation, and InferenceConfig design-by-contract parameter enforcement.")
    Container(hub_service, "HuggingFace Hub Service", "Python 3.11+, Subprocess", "Model catalog definitions and background downloader driving setup_env.py quantization and GGUF fetches.")
    Container(installer_svc, "Installation Manager", "Python 3.11+, Subprocess", "BitNet repository cloning, dependency verification, and CMake compilation runner.")
    Container(terminal_mgr, "Terminal Launch Manager", "Python 3.11+, Shlex", "Windows Terminal (wt.exe) and WSL command construction with secure argument escaping.")
  }

  System_Ext(bitnet_core, "llama-cli Binary", "BitNet 1-bit quantized inference executable.")
  System_Ext(hf_hub, "HuggingFace Hub", "Remote model repository.")
  System_Ext(win_term, "Windows Terminal", "Host terminal console emulator.")

  Rel(user, gui_layer, "Interacts with panels, logs, and controls through", "PyQt6 Desktop Interface")
  Rel(user, api_layer, "Sends HTTP requests to", "REST API (port 8000)")
  Rel(gui_layer, model_manager, "Queries available .gguf models and reads settings from", "Python Module Calls")
  Rel(gui_layer, chat_engine, "Streams token chunks and transitions state in", "Signal / Slots")
  Rel(gui_layer, hub_service, "Initiates background downloads from", "Worker Threads")
  Rel(gui_layer, installer_svc, "Checks status and triggers CMake builds via", "Worker Threads")
  Rel(gui_layer, terminal_mgr, "Launches external terminal sessions via", "wt.exe Launcher")
  Rel(api_layer, model_manager, "Reads discovered model inventory from", "Python API")
  Rel(chat_engine, bitnet_core, "Controls persistent subprocess execution over", "Standard I/O Pipes")
  Rel(hub_service, hf_hub, "Downloads model files and metadata over", "HTTPS")
  Rel(terminal_mgr, win_term, "Spawns terminal tabs and commands into", "Process Execution")
```

## Feature Map

| Capability | Component | Interface | Evidence |
| --- | --- | --- | --- |
| Model Discovery & Validation | Model Manager (`src/bitnet_launcher/models.py`) | Python API (`discover_models`, `ModelInfo`) | `tests/unit/test_models.py` |
| Inference Settings & Contracts | Config (`src/bitnet_launcher/config.py`) | Dataclasses (`InferenceConfig`, `BitnetConfig`) | `tests/unit/test_config.py` |
| Persistent Chat State Machine | Chat Engine (`src/bitnet_launcher/chat_session.py`) | Pure Python State Machine (`ChatSession`) | `tests/unit/test_chat_session.py` |
| Model Hub Catalog & Download | Hub Service (`src/bitnet_launcher/hub.py`) | Python API (`download_model`, `HubModel`) | `tests/unit/test_hub.py`, `tests/unit/test_hub_download.py` |
| Installation & CMake Build | Installer (`src/bitnet_launcher/installer.py`) | Python API (`check_installation`, `install_bitnet`) | `tests/unit/test_installer.py`, `tests/unit/test_installer_subprocess.py` |
| Terminal Launch Integration | Terminal Manager (`src/bitnet_launcher/terminal.py`) | Python API (`launch_terminal`, `build_command`) | `tests/unit/test_terminal.py` |
| Desktop GUI Workflow | GUI Layer (`src/bitnet_launcher/gui/`) | PyQt6 Widgets (`LauncherWindow`, Panels, Dialogs) | `tests/unit/test_app.py` |
| Local REST API & Auth | API Layer (`src/bitnet_launcher/api.py`) | FastAPI Endpoints (`/models`, `/health`) | `tests/unit/test_api.py`, `tests/unit/test_api_auth.py`, `tests/unit/test_api_cors.py` |
